# scripts/os-repos.txt — the canonical OS-repo fleet that vendors Core.
# ──────────────────────────────────────────────────────────────────────────────
# ONE list of the repos Core fans out into (B9). Read by scripts/sync-core.sh as the
# default TARGETS when no repos are named on the CLI.
#
# THIS FILE IS THE ONLY EDIT. Adding or removing a fleet target is one line, here.
# sync-core.sh, fleet-drift.sh and core-integrity.sh used to each keep a hardcoded
# fallback array for when this file was missing or unreadable, which meant FOUR
# coordinated edits and a fallback that ran in exactly the situation you were least
# likely to notice. They are gone (#669): every reader now goes through ONE parser,
# scripts/lib/common.sh :: load_os_repos, and there is no fallback list anywhere.
#
# CONSEQUENCE: if this file goes missing, is unreadable, or ends up with every entry
# commented out, the three fan-out gates FAIL LOUDLY (exit 2) rather than sweeping some
# other fleet. That is deliberate. A gate that quietly substitutes a stale list reads as
# coverage while covering nothing — the same reason real-bootstrap.yml errors instead of
# passing green when it derives zero legs. The advisory readers (audit-core.sh's sibling
# checks) record an environment SKIP for the same reason: they say they could not cover
# the fleet instead of implying they did.
#
# Format: one repo NAME per line. Blank lines and `#` comments ignored. The name is the
# GitHub repo, not a path: the fleet scripts look for a sibling directory of that name
# first, and fall back to whichever sibling clone's `origin` URL says it IS that repo
# (scripts/lib/common.sh :: resolve_repo_dir). So a repo RENAMED upstream keeps working
# from a clone still sitting under its old directory name — rename the line here, not
# every checkout in the fleet.
#
# Order is the fan-out order. Keep it case-insensitively alphabetical after
# dotfiles-MacBook (the reference implementation), which stays first so a smoke sync
# hits it soonest — i.e. Alpine sorts before Arch ('l' before 'r').
#
# DELIBERATELY ABSENT — not a Core-vendoring target (do not re-add):
#   dotfiles-Windows — the native Windows host layer is replicated from scratch
#     (PowerShell; not a one-to-one port of the Unix Core), so it carries no
#     vendored core/ subtree and sync-core.sh must never fan out into it.
# ──────────────────────────────────────────────────────────────────────────────
